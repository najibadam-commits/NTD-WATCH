# Screenshot storyboard

Status: internal plan plus capture record (not for external copies; the captions below are the externally usable part). The images were captured on 28 October 2026, before the Phase 4C reset/sync change, and have not been recaptured; this document makes no claim about any later screen change. Eight screenshots (`01` to `08`, plus the extra `07b`, which is diagnostic only and is not used) were captured from the real running application on 28 October 2026 and are saved in `artifacts/demo-evidence/`; none is generated, redrawn or illustrative, and their contents and limits are in `artifacts/demo-evidence/VERIFICATION_REPORT.md`. Every image must be a real capture from the running application (`npm run demo`, then `http://localhost:4173`), after pressing **Reset demo**. Routes below were checked against `apps/web/src/routes.tsx`, the screen components and the locale files.

General rules for every capture:

- Use a clean browser profile or a private window, 1440 x 900 for desktop shots and a 390 x 844 window (or the browser's phone emulation) for the CHW shots.
- Keep the **NTD-WATCH DEMO MODE** banner in frame wherever it is visible. Do not crop out the demonstration notices.
- Use made-up answers only. Do not type any real name, phone number or place.
- Caption each image with "Synthetic demonstration data. Prototype." when it is used in the application.
- Close developer tools, bookmarks bars and other tabs before capturing.
- Choose any role, press **Reset demo**, then **Yes, reset** before the session (the landing page has no reset button). The priority mix depends on the date, so note the capture date. Keep the number of made-up cases small so the women-and-girls referral total stays at "Not shown (fewer than 5)" (the current wording of that tile); reset again if it does not. Where the priority explanations say a count is hidden, the current wording is "not shown (small-count rule)", and "A count that is not shown is not zero."
- Capture programme shots 6 to 8 straight after a reset, then the CHW shots, then reset again.

## Not to be captured or implied

- No screenshot of a real user, partner, facility, patient or deployment.
- No image captioned as "field results", "pilot" or "outcomes".
- No image that shows an exact count from the women-and-girls aggregate, including the referral total, or any figure that could be read as a small count. The original `08-gis-priority.png` does not meet this rule: it contains exact small counts (for example 3 and 2) and clipped map labels, so it must not be shown. It is superseded by the remediated captures indexed in `artifacts/demo-evidence/SCREENSHOT_INDEX.md` (see `08l`, `08m`, `08n`; none is a privacy-protection claim). The prototype applies a small-count display rule to selected published programme views and exports. This is a client-side display measure, not a security control. Unresolved: differencing across separate queries and date ranges; exact WASH percentages and the vulnerability index; staff counts; direction labels and signal bands that can narrow hidden counts; the facility referral inbox, which returns record-level data; full records held in the browser database and mock server; the threshold of 5 is a placeholder not justified by specialist review; and there has been no independent privacy review or production-security validation.
